# Workbench Assistant downloads

This public repository distributes signed release packages only. The application source remains in the private roninstandardinc-glitch/eve repository.

## Downloads

The direct links below become active after the first signed public release:

- [Windows x64 installer](https://github.com/roninstandardinc-glitch/eve-downloads/releases/latest/download/Workbench-Assistant-Setup.exe)
- [Android APK](https://github.com/roninstandardinc-glitch/eve-downloads/releases/latest/download/Workbench-Assistant-Android.apk)
- [SHA-256 checksums](https://github.com/roninstandardinc-glitch/eve-downloads/releases/latest/download/SHA256SUMS.txt)

Check the release notes and verify the downloaded file against SHA256SUMS.txt. Android may ask you to allow your browser to install apps from this source.
